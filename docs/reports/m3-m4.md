# M3 / M4 報告（UI と多言語）— 2026-10-15

終了条件「§2 の操作がすべて通る」をヘッドレス Chromium の通し試験（12 項目）で確認。「全画面・全エラーで日英」「辞書のキー漏れがない」は型とテストで保証。WebGPU と AAC 入力（MP4 + AAC）は実機確認待ち。

## 実施したこと

- `src/app/`：状態（`Store`）、パイプライン（ファイル→デコード→44.1 kHz→分離→試聴用バッファ、保存 3 種）、画面（`View`：3 ステップ、進捗、エラー、詳細、クレジット）。
- `src/audio/player.ts`：ミュートした `<video>` / `<audio>` を操作系にし、Web Audio で「元の音／BGM除去後／BGMのみ」とスライダーを再生中に即時反映。再生・一時停止・シークに追従し、60 ms 以上ずれたら再同期。
- `src/i18n/`：辞書（ja / en）、初期言語（保存値 → `navigator.language`）、切替時の `<html lang>` と `document.title` の更新、`Intl` による数値・容量・%の表記。
- `src/styles.css`：ニュートラル＋アクセント 1 色、OS のライト／ダーク追従、最大幅 720 px、360 px で崩れない、`:focus-visible`、`prefers-reduced-motion`。
- `THIRD_PARTY_NOTICES.md`、`README.md` / `README.en.md`、`public/og.png`（`scripts/og/make_og.py`）、`favicon.svg`、`VERSION`。

## 確認できた事実（ヘッドレス Chromium 141、WebM 6 秒の試験メディア）

| 項目 | 結果 |
|---|---|
| 英語で起動（`navigator.language` = en-US）→ 日本語に切替 | 見出し・`<html lang>`・title が切り替わる |
| 音声なし MP4 | 「この動画には音声が入っていません」と選び直すボタン |
| ファイル情報 | `vp9_opus.webm · 0:06 · 1280×720` |
| 分離 | 12.1 秒（モデル 2.7 s ＋ デコード 0.7 s ＋ 分離 8.2 s） |
| 試聴 | 「BGMのみ」でスライダーが無効、「BGM除去後」で有効。再生が進む（音は Web Audio、ヘッドレスでは無音） |
| 動画を保存 | WebM 863 KB。映像パケット MD5 が入力と一致、音ズレ 0.00 / 0.00 ms |
| 音声を保存（WAV）／ 詳細の BGM | WAV 16 bit 48 kHz |
| 別のファイルを処理 | idle に戻る |
| キャンセル | 処理中に押すと「キャンセルしました」付きで loaded に戻り、再実行できる |
| コンソール | 警告・エラーなし（AudioSample の close 漏れを修正済み） |

- `showSaveFilePicker`（File System Access API）がある環境では保存先を先に選び、ストリームで書き出す。ない環境（やダイアログをキャンセルしたとき以外の失敗）はダウンロードにフォールバックする。ヘッドレス Chromium はダイアログを自動キャンセルするため、通し試験では API を無効化してダウンロード経路を確認した。
- メモリ：試聴用に mix / voice（セリフ＋効果音）/ music の 3 本を 44.1 kHz の Float32 で保持し、さらに speech（詳細の個別保存用）。10 分のステレオで約 850 MB の見込み。`navigator.deviceMemory` が 4 GB 以下の端末はチャンクを 10 秒にする。
